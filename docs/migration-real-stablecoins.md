# Migration: Fake → Real USDC/USDT on Monad Testnet

## Overview

Replace our custom-deployed TestUSDC/TestUSDT (mintable ERC20s) with Circle's official USDC and a real USDT deployment on Monad testnet. This removes the StableFaucet and all minting capabilities — tokens must be acquired externally.

## USDC Budget

With fake tokens we minted millions freely. Real testnet USDC comes from [Circle's faucet](https://faucet.circle.com/) (~10 USDC per drip).

**Current pool liquidity (fake tokens):**
- WMON/USDC: ~8,950,000 USDC
- WMON/USDT: ~8,950,000 USDT
- USDC/USDT: ~2,000,000 each (from initial seed)

**Target pool liquidity (real tokens) — dramatically smaller:**

| Pool | USDC needed | USDT needed | WMON needed |
|------|-------------|-------------|-------------|
| USDC/WMON | 5,000 | — | 5 |
| USDT/WMON | — | 5,000 | 5 |
| USDC/USDT | 5,000 | 5,000 | — |
| Rebalancer buffer | 2,000 | 2,000 | — |
| **Total** | **~12,000** | **~12,000** | **~10** |

At 10 USDC per faucet drip, accumulating 12K requires ~1,200 drips or finding a larger source (bridge, whale, batch faucet). Scale down if needed — even 1,000 per pool works for testing.

## Breaking Changes

| Area | Impact | Mitigation |
|------|--------|------------|
| **Rebalancer** | Can no longer mint tokens to rebalance pools | Pre-fund operator wallet; add balance check that fails loudly instead of silently minting |
| **Faucet** | No user-facing faucet for stablecoins | Link to Circle faucet; consider a thin wrapper that drips from a pre-funded wallet |
| **Pool liquidity** | Orders of magnitude less → higher slippage | Adjust target price in rebalancer config; add slippage warnings in UI |
| **Existing pools** | Old fake-token pools remain on-chain | They'll stop appearing once TokenRegistry lists new tokens as core; old pairs not routed |
| **Forge tests** | Still use TestUSDC/TestUSDT locally | No change needed — tests deploy their own instances |
