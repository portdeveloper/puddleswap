~ why puddleswap ~

A DEX shaped for testnet.

Forked from Uniswap V2, deployed on Monad Testnet, wrapped in a frontend with no backend at all.

Star routing

Every swap checks paths through USDC, USDT, and WMON in one batched RPC call. Any token with a pool against a core token is reachable from any other. The best quote wins.

No backend

The frontend talks to Monad testnet directly via RPC. There is no app backend, no KYC, and no data collection. Your wallet sends the transaction.

Permissionless pools

Pick any two ERC-20s, seed initial liquidity, get LP tokens. Anyone can register a token on-chain. There is a 7-day cooldown and basic anti-spam.
